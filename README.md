# Learning at IT - Final Year Project

## Machine Learning for Heart Disease Classification

This repository contains my final year project and learning journey in Data Science and Machine Learning during my IT internship.

### 🎓 Project Overview

The main project focuses on **Heart Disease Classification using Machine Learning**, an end-to-end machine learning solution that predicts whether a patient has heart disease based on clinical parameters.

### 📊 Project Objectives

- Develop a machine learning model capable of predicting heart disease
- Explore and analyze medical datasets
- Apply various classification algorithms and compare their performance
- Document the complete data science workflow from problem definition to model evaluation

### 🛠️ Technologies Used

- **Python 3.x** - Primary programming language
- **NumPy** - Numerical computing and array operations
- **Pandas** - Data manipulation and analysis
- **Matplotlib** - Data visualization
- **Scikit-learn** - Machine learning algorithms and tools
- **Jupyter Notebook** - Interactive development environment

### 🚀 Getting Started

#### Prerequisites

- Python 3.8 or higher
- Jupyter Notebook or JupyterLab
- pip (Python package manager)

#### Installation

1. Clone the repository:
```bash
git clone https://github.com/ibnmikhail48/Learning-at-IT.git
cd Learning-at-IT
```

2. Install required dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open and run the notebooks in your browser

### 📚 Project Workflow

The main heart disease classification project follows a structured approach:

1. **Problem Definition** - Defining the prediction task
2. **Data Collection** - Gathering medical datasets
3. **Exploratory Data Analysis** - Understanding data patterns
4. **Feature Engineering** - Preparing features for modeling
5. **Model Development** - Training classification algorithms
6. **Model Evaluation** - Assessing model performance
7. **Results & Insights** - Drawing conclusions
